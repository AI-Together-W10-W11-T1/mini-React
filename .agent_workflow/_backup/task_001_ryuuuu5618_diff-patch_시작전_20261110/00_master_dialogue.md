## 0단계 인터뷰

- Q: Phase 2 웹페이지 주제를 지금 정할까? (후보: 게시글 피드 · 할 일 · 가계부 · 주문 키오스크)
- A: 일단 정하지 않고 진행한다. → Phase 2 주제 미정
- Q: 이번 task의 브라우저 확인(e2e) 범위는? (케이스 버튼 페이지 / Patch 버튼까지 / 단위 테스트만)
- A: 케이스 버튼 페이지로 진행한다. 미리 정한 변경 버튼(D-01~05 · 무변경 · 복합 변경)으로 diff → patch를 확인. 편집 UI · domToVNode · History는 다음 task
- Q: 인터뷰 방식은?
- A: grill-me 스킬 방식으로 진행해 React 흐름을 공부하고 이해하면서 구현하고 싶다 → 플러그인에 `mini-react-kit:grill-me` 추가 (0.4.5)
