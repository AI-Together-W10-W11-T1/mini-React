| A5 | e2e 공통 | Playwright는 예상하지 못한 alert를 **자동으로 닫는다**. 검사기가 정상 글을 잘못 막아도 alert가 조용히 사라진다 | 헬퍼에 "guard 스펙 밖에서 dialog가 뜨면 테스트 실패" 장치를 둔다. **모든 스펙에서 콘솔 error 0건**도 공통으로 확인 (지금은 QA-1 · A2 · A4만) |
