## 읽을 때 주의

- 한 번 잰 값이다. 같은 페이지를 세 번 돌렸고 실행마다 값이 달랐다 (위는 첫 번째 실행). 알고리즘 우열 판단에 쓰지 않는다 (PRD §8.2)
- B-03 · B-04의 시간은 대시보드 표에만 나왔고 기록 파일에 옮겨 두지 않았다. 대시보드를 다시 돌리면 채울 수 있다
- B-06 · B-07은 엔진 `update()` 한 덩어리로 재서 M-04 ~ M-06 단계 시간이 따로 없다
- B-07의 patch 줄 대부분은 SET_EVENT다. 렌더마다 핸들러가 새 함수라 생기는 줄이고 실제 DOM은 바꾸지 않는다
- MutationObserver 기록 수는 DOM API 호출 수와 같지 않다. patch 줄 · 관찰 기록 · 추가 / 제거 노드 수를 따로 적었다 (PRD §7)
- 시연 앱 mini-figma (task_004 · 005)는 대시보드로 재지 않았다. 대신 단위 테스트가 동작마다 patch 줄 수를 확인한다 (예: 메인 색 변경 = SET_STYLE 3줄, 레이어 [↓] = MOVE 1줄)
